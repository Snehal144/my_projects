# Habit Tracker

This project is a Habit Tracker application built using Streamlit. It allows users to track their habits over a week, marking them as completed or not, and provides a user-friendly interface for managing their habits.

## Features

- Track multiple habits.
- View a weekly calendar to mark habits as completed.
- Save and load completion status.
- Simple and intuitive user interface.

## Installation

To set up the project, follow these steps:

1. Clone the repository:

   ```
   git clone <repository-url>
   cd habit-tracker
   ```

2. Install the required dependencies:

   ```
   pip install -r requirements.txt
   ```

## Running the Application

To run the application, execute the following command:

```
streamlit run app.py
```

This will start the Streamlit server and open the application in your default web browser.

## Usage

- Add your habits in the input field provided.
- Use the checkboxes to mark habits as completed for each day of the week.
- Click the "Save Completion" button to save your progress.
